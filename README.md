# 개발한입

개발 지식을 읽고 복습하며 이력서 기반 면접을 준비하는 웹 앱입니다.

## 주요 기능

- 카테고리별 학습 콘텐츠 탐색과 검색
- 학습 / 이력서 탭 전환 및 각각의 완료율 관리
- 이력서 기반 면접 질문 167개를 전체 목록에서 검색·북마크로 탐색
- 질문별 이력서 근거, 문단형 답변 예시, 개인 경험 보완 안내와 공식 문서
- 학습 완료 표시 및 일괄 변경
- 즐겨찾기 저장과 필터
- 학습 완료 및 즐겨찾기 기기 동기화
- PWA 설치 및 오프라인 학습

학습 기록은 브라우저에 저장됩니다. 동기화 ID를 설정하면 기기 간에 공유할 수 있습니다.

## 로컬 실행

Node.js 22 이상을 권장합니다.

```bash
npm run build
python3 -m http.server 4173 -d dist
```

## 콘텐츠 관리

학습 원본은 `notion_technical_questions_final.txt`입니다. 내용을 검수한 다음 승인하고 빌드합니다.

```bash
npm run content:approve
npm run build
```

`npm run quality`는 승인된 학습 원본과 용어, 이력서 데이터 구조를 검사하고 기록 저장·동기화 호환성 테스트를 실행합니다. 동기화 API 테스트는 Redis 대역을 사용하며 운영 저장소에는 접근하지 않습니다. 자동 검사는 기술적 정확성과 설명 품질에 대한 직접 검수를 대신하지 않습니다.

이력서 콘텐츠는 `resume-content/01-*.mjs`부터 `06-*.mjs`까지 프로젝트별로 관리합니다. 각 질문은 고정 ID, Figma 텍스트 노드와 줄 번호, 질문 유형, 질문, 답변, 선택적인 개인 경험 보완 안내와 참고 문서 키를 가집니다. 질문 순서를 바꾸더라도 ID는 유지해야 완료·북마크 기록이 보존됩니다.

`resume-source.json`은 2026-09-28에 읽은 이력서 7페이지의 근거 자료입니다. 임시 작성한 그루모바일·지원 동기와 연락처는 제외했습니다. 빌드에는 이 파일 전체를 복사하지 않고 질문이 참조한 문장만 포함합니다. 기술 설명은 프로젝트 당시의 사용 방식과 현재 공식 문서의 버전 차이를 고려해 검수합니다. 확인되지 않은 개인 경험·성과는 답변에서 사실로 단정하지 않습니다.

```bash
npm run resume:build     # 원고와 근거로 resume-content.json 생성
npm run resume:validate  # ID, 근거 연결, 답변, 참고 문서, 제외 대상 검증
npm run build           # 이력서 재생성 + 두 콘텐츠 검증 + dist 생성
```

기존 학습 ID `q-*`와 이력서 ID `resume-*`는 동일한 저장·동기화 형식을 사용하되 각 탭의 집계와 필터는 별도로 동작합니다. 새 이력서 파일도 PWA 오프라인 캐시에 포함됩니다.

상세 절차는 [CONTENT_WORKFLOW.md](./CONTENT_WORKFLOW.md)를 참고하세요.

## 기술 구성

Vanilla JavaScript, HTML/CSS, PWA Service Worker, Node.js 빌드 도구, Vercel 배포 및 Redis 기반 동기화 API를 사용합니다. `dist/`와 `.vercel/`은 Git에서 제외됩니다.
